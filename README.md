# 06 · 고사리와 형태 — 도자 · 식재 스튜디오

> **[Portfolio Maker](https://portfoliomaker.site)** 로 만든 견본 포트폴리오입니다.
> 코드 한 줄 쓰지 않고, 브라우저에서 클릭과 입력만으로 만들었습니다.

## 이 견본이 쓴 설정

| | |
|---|---|
| 템플릿 | 매거진 3단 |
| 테마 | 세이지 |
| 글꼴 | Fraunces |
| 구성 | 3페이지 (Home · Shop · Contact) · 한 페이지(퀵메뉴) |
| 3D | `fern.glb` + 아트 스튜디오 HDRI 스카이박스 |
| 효과 | 호버 프리뷰 · 패럴랙스 · 틸트 카드 · 스크롤 등장 · 인트로 로더 · 부드러운 스크롤 |
| 갤러리 | 4열 그리드 · 8개 카드 |
| 사진 | 13장 |
| 용량 | 약 4.3 MB |

**Home** — 세 칸 매거진 레이아웃에 프로필 카드 · 흐르는 태그 목록 · 숫자 통계, 그 아래 4열 갤러리와 3D 고사리.
**Shop** — 덮기 전환 슬라이더, 사는 법 4단계, 입고 알림 CTA.
**Contact** — 스크롤 확대 커버와 연락처.

3D 모델은 첫 화면이 아니라 스크롤 중간에 배치해, 방문자가 그 자리에 도달할 때만 내려받습니다.

## 직접 열어서 뜯어보기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `fern-and-form.pbproj` 선택

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 결과물은 **단일 HTML** 또는 **폴더 ZIP** 으로 내려받습니다 — 이 저장소가 그 ZIP 그대로입니다
- 만든 프로젝트는 `.pbproj` 로 저장해 두었다가 언제든 다시 불러옵니다
